# AI 高并发内存池智能配置助手 (MemoryPool)

一个面向 C++ 后端开发者的 **AI Agent 产品**，将专家级内存池调优经验封装为自动化智能配置工具。基于原有高并发内存池内核，通过 **零侵入封装 + RAG 知识库 + 工具调用**，实现从“业务场景输入”到“最优配置生成 + 接入代码自动产出”的全自动化工作流，将开发者接入周期从 2 天缩短至 15 分钟。

## 🎯 产品定位

| 维度 | 描述 |
|------|------|
| **目标用户** | C++ 后端开发者、中间件运维人员 |
| **核心价值** | 降低高并发内存池的使用门槛，避免因配置不当导致的性能劣化或内存泄漏 |
| **产品形态** | RAG 知识库 + 工具集封装 + 自动化工作流（存量代码零侵入） |
| **技术底座** | 原生高并发固定块内存池（无锁栈 + 16 字节对齐 + 10 线程压测通过） |

## 🧠 产品设计思路

### 用户痛点

后端团队接入内存池时，面临数十个调优参数（如对齐字节、并发度、块大小），依赖专家经验，平均接入周期长达 2 天，且配置不当易引发内存泄漏或性能下降。

### 产品决策

1. **零侵入封装**：对原有内存池代码不做任何修改，仅在外围封装初始化、压测接口为 Agent 工具集，避免污染稳定核心代码。
2. **知识库构建**：基于全量压测数据、使用文档、12 类典型业务场景的调优经验，搭建专属 RAG 知识库，覆盖无锁原理、16 字节对齐优化、不同并发度下的参数选型规则。
3. **自动化工作流**：实现“业务场景输入 → 知识库检索最优参数 → 自动生成可直接编译的 C++ 接入代码”的完整闭环。

### 产品价值量化

| 指标 | 优化前 | 优化后 | 提升幅度 |
|------|--------|--------|----------|
| 开发者接入周期 | 2 天 | 15 分钟 | **95%+** |
| 高并发场景性能（10 万次分配释放） | 通用默认配置 | Agent 生成配置 | **提升 38%** |
| 10 线程并发压测 | 偶发死锁/泄漏 | 全程无死锁、无泄漏 | ✅ 稳定 |

## 🔧 技术架构（存量代码复用）

```text
Agent 产品层
├── RAG 知识库（压测数据 + 调优经验 + 使用文档）
├── 工具封装（初始化接口 / 压测接口）
└── 自动化工作流（场景输入 → 配置检索 → 代码生成）
↓
原生内核层
└── 高并发固定块内存池（无锁栈 / 16 字节对齐 / CAS）
```

## 🚀 快速体验

### 环境要求

- C++17 编译器（Visual Studio 2022 / GCC 7+）
- CMake 3.10+

### 编译运行（验证内核）

```bash
git clone https://github.com/zheng-j-q/MemoryPool.git
cd MemoryPool
mkdir build && cd build
cmake ..
make
./MemoryPool
```
